# Spec: v0.11.0 「加固」(重启补跑 / argon2id / 登录限速 / 通知签名 / 会话管理 / 指标补全)

## F1 重启补跑(catchup)

- 任务级 `catchup`(bool,默认 false)——与 watchdog 的判定逻辑同源:
  期望时间 = 时区下 now 之前最近的一次 cron 触发点(宽限 5 分钟);若该时间之后
  无任何执行尝试(含失败),且期望时间在 `CATCHUP_MAX_LAG_HOURS`(默认 24)内
  → 启动时补跑一次(后台 spawn,复用完整管线:并发互斥/重试/通知)
- 抽取 `watchdog::missed_expected(db, task) -> Option<String>` 供 scan 与 catchup 共用;
  维护模式恢复为开启时**不补跑**;once 任务天然不参与(last_due 返回 None)
- 前端表单"重启补跑"复选框(紧邻漏跑告警);CLI `--catchup`

## F2 密码哈希升级(argon2id)

- 新依赖 `argon2 = "0.5"`(纯 Rust);`users.password_hash` 存 PHC 字符串(`$argon2id$...`)
- `seed_admin` 直接写 argon2id;`verify_admin`:存量为 argon2 → PasswordVerifier;
  存量为 sha256(旧版本种子)→ 比对成功后**惰性升级**为 argon2id 再返回 true
- token/hook secret 的 sha256 哈希不变(那是随机值非口令,无需 KDF)

## F3 登录限速

- 内存滑动窗口:同一用户名(小写)15 分钟内 ≥10 次失败 → 429
  "too many login attempts";成功登录清零;重启清零(可接受,注明)

## F4 通知 webhook 签名

- 配置 `NOTIFY_WEBHOOK_SECRET`(config.toml `notify_webhook_secret`,默认空 = 不签名)
- 通用 webhook 渠道:请求头附 `X-i-rs-Signature: sha256=<HMAC-SHA256(secret, body)>`
  (hex);飞书/钉钉渠道不受影响(有自有签名机制);Notifier 构造函数接收 secret
- 单元测试:本地 TCP 接收端验证头存在且 HMAC 正确

## F5 会话管理

- db:`list_sessions() -> Vec<(token_hash, created_at, expires_at)>`(哈希即标识,非敏感)、
  `revoke_session(token_hash) -> bool`
- API(需认证):`GET /api/auth/sessions`、`DELETE /api/auth/sessions/:hash`
- 前端:设置对话框新增 Sessions 标签页(列表 + 吊销;过期状态客户端判定)
- CLI:`session list` / `session revoke <hash>`

## F6 指标补全

- 新模块 `metrics.rs`:`Metrics`(原子计数:耗时桶 10ms→120s 共 12 档 + sum/total、skipped)
- Executor 每次 execution 结束 record(duration_ms);skipped 落库处 bump
- /metrics 增量渲染:`irs_execution_duration_seconds`(histogram,累计桶)、
  `irs_executions_skipped_total`(counter)、`irs_maintenance_active`(gauge)

## 冒烟

1. catchup:建 cron 任务(每小时)catchup=true → 重启服务器 → 补跑记录出现;
   catchup=false 的对照任务无补跑;维护模式重启不补跑
2. argon2:seed admin → login 成功 → users 表密码哈希以 `$argon2` 开头;
   手写 sha256 旧哈希 → login 成功且哈希被升级
3. 限速:连续 11 次错误密码 → 第 11 次起 429
4. 签名:本地 python 接收端收到 X-i-rs-Signature 且 HMAC 校验通过
5. 会话:登录两次 → 列表 2 条 → 吊销 1 条 → 该 token 401
6. metrics:跑一个任务后 /metrics 出现 histogram/skipped/gauge 行
7. 回归:cargo test 全绿、clippy 零警告、前端 build/lint
